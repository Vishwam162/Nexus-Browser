# 🌐 Nexus Browser
**Precision Web Experience | Developed by Vishwam Phalke**

Nexus is a standalone desktop browser built using Electron and the Chromium engine. It features a custom **Cybernetic Sunset** UI, glassmorphism design, and advanced DOM injection to rebrand the web experience.

## ✨ Features
* **Cyber UI:** A custom-built interface with neon accents and glassmorphism.
* **Branded Search:** Google logo is dynamically replaced with the NEXUS identity.
* **Standalone:** Compiles to a native Windows `.exe`.
* **Theming:** Injects custom CSS into search results for a unified dark-glass aesthetic.

## 🚀 Getting Started
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/Nexus-Browser.git`
2. Install dependencies: `npm install`
3. Launch the app: `npm start`
